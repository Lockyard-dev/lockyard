# Lockyard CLI — правки приёмки

Сервер реестра — соседний репозиторий `cloud`. Полное описание — в `cloud/LOCKYARD-FIXES.md`. Правки уже в дереве этого репозитория.

## Что в этом патче

- `lockyard task reject` принимает `--evidence`. Для локальной accepted-задачи доказательство обязательно, история submit не стирается, исполнитель сам себя не отзывает. Для облачной заявки в `done` CLI шлёт переход в `ready` вместе с новой evidence.
- Сдача code-цели с голым хешем коммита обрывается в клиенте до POST. Нужен `<ревизия>:<путь файла>`. Цель `ci_passed` по-прежнему принимает текст прогона.
- `lockyard setup` и doctor для Cursor пишут, что сервер MCP не стартует, пока его не включат в Settings → MCP. Reload без этого одобрения ничего не запускает. Сам Lockyard одобрение нажать не может.

Потолок четырёх evidence на отзыв принятой заявки снят в сервере (`cloud`): полная карточка всё равно записывает причину и новую evidence. Обычное добавление evidence по-прежнему останавливается на четырёх.
